## sf template generate lightning component

Generate a bundle for an Aura component or a Lightning web component.

```
sf template generate lightning component [flags]
```

### Options

```
      --api-version string   Override the api version used for api requests made by this command
  -h, --help                 help for component
      --json                 Format output as json.
  -n, --name string          Name of the generated metadata.
  -d, --output-dir string    Directory for saving the created files. (default ".")
  -t, --template string      Template to use for file creation. (default "default")
      --type string          Type of the component bundle. (default "aura")
```
