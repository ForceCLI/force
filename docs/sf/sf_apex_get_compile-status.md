## sf apex get compile-status

Fetches the compilation status for Apex classes that are currently invalid or have compilation warnings.

```
sf apex get compile-status [flags]
```

### Options

```
      --api-version string   Override the api version used for api requests made by this command
  -h, --help                 help for compile-status
      --json                 Format output as json.
  -o, --target-org string    Username or alias of the target org.
```
