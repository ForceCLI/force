## sf package version promote

Promote a package version to released.

```
sf package version promote [flags]
```

### Options

```
      --api-version string      Override the api version used for api requests made by this command
  -h, --help                    help for promote
      --json                    Format output as json.
  -n, --no-prompt               Don't prompt to confirm setting the package version as released.
  -p, --package string          ID (starts with 04t) or alias of the package version to promote.
  -v, --target-dev-hub string   Username or alias of the Dev Hub org.
```
