## sf template generate static-resource

Generate a static resource.

```
sf template generate static-resource [flags]
```

### Options

```
      --api-version string   Override the api version used for api requests made by this command
  -h, --help                 help for static-resource
      --json                 Format output as json.
  -n, --name string          Name of the generated metadata.
  -d, --output-dir string    Directory for saving the created files. (default ".")
      --type string          Content type (mime type) of the generated static resource. (default "application/zip")
```
