## sf org create snapshot

Create a snapshot of a scratch org.

```
sf org create snapshot [flags]
```

### Options

```
      --api-version string      Override the api version used for api requests made by this command
  -d, --description string      Description of snapshot.
  -h, --help                    help for snapshot
      --json                    Format output as json.
  -n, --name string             Unique name of snapshot.
  -o, --source-org string       ID or locally authenticated username or alias of scratch org to snapshot.
  -v, --target-dev-hub string   Username or alias of the Dev Hub org.
```
