## sf org resume scratch

Resume the creation of an incomplete scratch org.

```
sf org resume scratch [flags]
```

### Options

```
  -h, --help              help for scratch
  -i, --job-id string     Job ID of the incomplete scratch org create that you want to resume.
      --json              Format output as json.
  -r, --use-most-recent   Use the job ID of the most recent incomplete scratch org.
  -w, --wait int          Number of minutes to wait for the scratch org to be ready.
```
