## sf package version create report

Retrieve details about a package version creation request.

```
sf package version create report [flags]
```

### Options

```
      --api-version string                 Override the api version used for api requests made by this command
  -h, --help                               help for report
      --json                               Format output as json.
  -i, --package-create-request-id string   ID (starts with 08c) of the package version creation request you want to display.
  -v, --target-dev-hub string              Username or alias of the Dev Hub org.
```
