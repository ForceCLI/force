## sf package delete

Delete a package.

```
sf package delete [flags]
```

### Options

```
      --api-version string      Override the api version used for api requests made by this command
  -h, --help                    help for delete
      --json                    Format output as json.
  -n, --no-prompt               Don’t prompt before deleting.
  -p, --package string          ID or alias of the package or package version to delete.
  -v, --target-dev-hub string   Username or alias of the Dev Hub org.
```
