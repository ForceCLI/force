## sf cmdt generate field

Generate a field for a custom metadata type based on the provided field type.

```
sf cmdt generate field [flags]
```

### Options

```
  -s, --decimal-places int            Number of decimal places to use for number or percent fields.
  -h, --help                          help for field
      --json                          Format output as json.
  -l, --label string                  Label for the field.
  -n, --name string                   Unique name for the field.
  -d, --output-directory string       Directory to store newly-created field definition files.
  -p, --picklist-values stringArray   Picklist values; required for picklist fields.
  -f, --type string                   Type of the field.
```
