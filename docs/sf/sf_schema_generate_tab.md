## sf schema generate tab

Generate the metadata source files for a new custom tab on a custom object.

```
sf schema generate tab [flags]
```

### Options

```
  -d, --directory string   Path to a "tabs" directory that will contain the source files for your new tab.
  -h, --help               help for tab
  -i, --icon string        Number from 1 to 100 that specifies the color scheme and icon for the custom tab. (default "1")
      --json               Format output as json.
  -o, --object string      API name of the custom object you're generating a tab for.
```
